# 💨 Solder-Fume-Extractor
A DIY Solder Fume Extractor + Air Quality Sensor for soldering applications. Encompasses a control board with the air quality sensor, a 12V PC fan, activated carbon filter, and custom-designed 3d-printed casing to house everything.
